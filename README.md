## 📌 Overview

The **Medical Insurance Cost Prediction** platform integrates a Machine Learning model with a modern web application to provide estimated insurance costs based on six input features:

- Age
- Sex
- BMI
- Number of children
- Smoking status
- Region

The application provides a complete user workflow including registration, authentication, prediction, prediction history, profile management, and a responsive dashboard.
